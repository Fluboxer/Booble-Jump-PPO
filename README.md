# Booble-Jump-PPO
Небольшой проект с игрой в стиле **Doodle Jump** и агентом обучения с подкреплением на основе **PPO (Proximal Policy Optimization)**.

Проект написан на Python и объединяет собственную игровую логику, окружение Gymnasium, нейронную сеть на PyTorch и интерактивный режим игры через PyGame-CE.

### Возможности

- обучение агента с помощью PPO;
- собственная игровая среда на базе Gymnasium;
- векторизованное обучение в нескольких окружениях;
- платформы разных типов: обычные, движущиеся, разрушаемые и пружинные;
- запись статистики обучения;
- игровой режим с возможностью переключения между ИИ и ручным управлением;
- настройка количества окружений, числа шагов и LR через консоль.

### Стек

- Python 3.10+
- PyTorch
- Gymnasium
- PyGame-ce
- NumPy
- psutil

### Установка

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv

# Linux/macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
```

Если для PyTorch нужна поддержка CUDA, установите сборку PyTorch, подходящую для вашей версии CUDA, согласно [официальной документации PyTorch](https://pytorch.org/get-started/locally/).

### Запуск

Активируйте виртуальное окружение, если оно ещё не активировано:

```bash
# Linux/macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

Запустите скрипт:

```bash
python main.py
```

После запуска доступны режимы:

```text
1 - обучение агента со стандартными настройками
2 - игра с последним обученным агентом
9 - обучение с выбором параметров
0 - выход
```

При выборе режима игры программа использует последнюю доступную модель из каталога `models/`

### Структура проекта

```text
booble_jump_ppo/
├── main.py          # консольный интерфейс, обучение и запуск игры
├── config.py        # конфигурация игры, PPO и наград
├── game_env.py       # игровая логика и физика
├── gym_env.py      # обёртка игры в Gymnasium-среду
├── ppo_agent.py    # состав нейронной сети, PPO-агент и логика его работы
├── training.py     # цикл векторизованного обучения
└── utils.py        # вспомогательные функции

models/              # сохранённые модели и чекпоинты
logs/                # журналы обучения и реестр моделей
```

### Управление в игре

- `SPACE` — переключить режим между ИИ и человеком;
- `R` — перезапустить игру;
- `ESC` — выйти.

### Примечания

Обучение может быть ресурсоёмким: необходимое время зависит от числа окружений, количества шагов и доступного CPU/GPU, а так же количества оперативной памяти. Проект предназначен прежде всего для экспериментов - например, можно поменять состав нейронной сети в ppo_agent.py или подкрутить количество нейронов в config.py и посмотреть, что будет
